# Week 2 Smart Calculator

Run the calculator's desktop interface with Python:

```text
python calculator_with_search.py
```

To use the command-line menu instead, run:

```text
python calculator_with_search.py --cli
```

Use the **Calculator** tab for addition, subtraction, multiplication, division,
exponents, or remainders; **Solve for x** to enter an equation such as
`2x + 3 = 11`; and **Search math** to find concepts and formulas in the
glossary. In the command-line menu, choose the corresponding numbered option
or type `Q` to quit.
