# My Copilot Experience

I used Copilot to help create a Python calculator with a search feature. When I
first asked for `calculator_with_search.py`, “search” could have meant several
things, so Copilot asked me to clarify. I chose a built-in search for math
concepts and formulas.

Copilot helped write a menu-driven program with addition, subtraction,
multiplication, division, exponents, and remainders. It also added a glossary
that can be searched for terms such as “triangle” and “percentage,” and handles
errors like division by zero. Copilot updated the README with instructions for
running the program.

I asked Copilot to create this reflection file as well. After the calculator
was created, its operations and search behavior were checked with small tests.
Those checks passed. This showed me that Copilot can help turn an idea into a
working starting point, but it is still important to clarify what I want and
test the result.


Things that worked well were:
that I could prompt copilot for the basic math examples.
I could make it launch into a UI.
As annoying as the prompts were they were also really nice to work with.

Challenges:
It doesnt give you a basic prompt, I would say its too complex for a normal user.
Honestly just the fact that it takes too long to fill in code.

Judgment:
It helps that im good at math, but I would say there was times where I would question what mathmatic equation it was grabbing.
